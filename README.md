# 🏕️ Glamping Management System

Приложение для автоматизации работы глэмпинга. Позволяет вести учёт объектов размещения, клиентов, заселений и дополнительных услуг.

## 🛠️ Стек технологий
*   **Язык:** Kotlin
*   **UI:** Jetpack Compose (Material 3)
*   **Архитектура:** MVVM (ViewModel + Repository)
*   **База данных:** Room (SQLite) с поддержкой транзакций и триггеров
*   **Навигация:** Navigation Compose
*   **Асинхронность:** Kotlin Coroutines & Flow

## ✨ Основные возможности
*   **Панель администратора:** Отображение выручки, количества проживающих и последних заселений.
*   **Управление объектами:** Добавление домиков/палаток с фото (BLOB), ценой, категорией комфорта и вместимостью.
*   **Управление клиентами:** База клиентов с валидацией телефона и паспорта.
*   **Оформление заселения:** Выбор клиента, объекта, дат и дополнительных услуг. Всё сохраняется в **одной транзакции** (если объект занят, откатывается всё).
*   **Справочники:** Управление категориями комфорта и дополнительными услугами (прайс-лист).

## 🚀 Как запустить проект
1.  Установите готовый APK-файл из папки `apk/app-debug.apk` на ваш Android-смартфон.
2.  Или откройте проект в **Android Studio**, дождитесь синхронизации Gradle и запустите на эмуляторе/устройстве.
